Choose from 1 to 64 images, add files quickly, and adjust your collage directly on the canvas.

- Set the image count or add empty panels. Auto Grid, Columns, and Rows adapt to your count.
- Import several images at once. The layout grows to fit them without leaving extra files out.
- Drag images between panels to swap their placement, keeping each image's crop and colour adjustments.
- Drag shared sides and corners to resize connected panels without gaps or overlaps.
- Angled dividers move parallel to themselves, keeping their original angle. Handles follow the actual slanted edges.
- Hold Shift while dragging, or enable Pan image, to adjust the crop within a panel.
- Undo or redo layout changes, swaps, and resizing. Press Escape during a resize to cancel it.

Includes the original 18 editorial layouts, project save/load, autosave recovery, and JPEG, PNG, and WebP export.

**Install:** Download the x64 installer for Intel or AMD Windows computers, or the ARM64 installer for ARM-based Windows computers. Both are self-contained and install per user without administrator access.

**Validation:** Windows x64 and ARM64 builds; x64 smoke tests covering flexible layouts, shared dividers, angle preservation, imports, undo/redo, saved projects, and image exports. SHA256SUMS.txt contains installer checksums.
